
# Create: Intergalactic

A Space mod for Create Aeronautics based on No Mans Sky

Feature Roadmap: (unordered)
- [ ] Low memory space dimension.
- [ ] Procedural galaxy and planet generation.
- [ ] API for preset/premade planets.
- [ ] Pressure systems.
- [ ] Seamless space to planet dimensional travel.
- [ ] Proportional gravity based on planet size/density
- [ ] Atmospheric composition (gasses, sky color, etc)
- [ ] Planetary orbits
- [ ] Airlocks

Bonus Features:
- [ ] Satellite systems
- [ ] Black Holes
- [ ] Light Speed travel
